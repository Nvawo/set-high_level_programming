# Python - Almost a Circle

This project is part of the Python high-level programming curriculum.

The project focuses on:

- Unit testing
- Classes and objects
- Inheritance
- JSON serialization and deserialization
- File handling
- Argument handling
- PEP 8 validation
- Test-driven development

## Testing

All classes and methods in this project must be unit tested.

To run all tests:

    python3 -m unittest discover tests

The tests should verify that the implemented classes and methods behave correctly.

## PEP 8

All Python files should follow PEP 8 standards.

PEP 8 can be checked with:

    pycodestyle *.py
